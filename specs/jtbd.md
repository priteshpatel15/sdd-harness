# JTBD

## Product

SDD Harness

## Audience

Developers using AI coding agents to build or change software under enforceable specifications.

## Problem

AI-assisted implementation can drift from stakeholder intent, skip validation, mutate live data during tests, and report success without durable evidence.

## Job

When a developer delegates work to an agent, they need the harness to preserve intent, force spec approval, require TDD and validation evidence, and block completion until the evidence matches the approved semantic contract.

## Situation

The harness is used from a local CLI and thin skills against greenfield or brownfield projects.

## Motivation

Make AI-assisted delivery repeatable, auditable, and safe enough for real project work.

## Desired Outcome

Every completed feature has approved specs, strict task evidence, isolated validation data, semantic verification, review disposition, changelog evidence, and structured telemetry.
